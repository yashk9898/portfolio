## 🚀 Flagship Projects

### 🤖 [ATS.AI — Enterprise AI Recruitment Platform](https://crypthire-ai.vercel.app)
> **AI-powered intelligence engine automating multi-format resume parsing and candidate role-fit scoring.**

- **Live Application**: [crypthire-ai.vercel.app](https://crypthire-ai.vercel.app)
- **Candidate Application Portal**: [crypthire-ai.vercel.app/portal/apply](https://crypthire-ai.vercel.app/portal/apply)
- **Admin Dashboard**: [crypthire-ai.vercel.app/portal/admin](https://crypthire-ai.vercel.app/portal/admin)
- **Tech Stack**: `Next.js 16.2` • `React 19` • `TypeScript 5` • `MongoDB Atlas` • `Docker` • `Nodemailer` • `pdf-parse` • `Tailwind CSS`
- **Features**:
  - Automated PDF resume parsing and candidate compatibility score generation
  - Full recruitment pipeline management from submission to interview
  - Automated email dispatch via Nodemailer
  - Multi-stage non-root Docker containerization (<200MB footprint) with Docker health checks

> **Unified digital education system replacing fragmented WhatsApp groups and spreadsheets.**

- **Tech Stack**: `React.js` • `Next.js` • `Node.js` • `MongoDB` • `Socket.IO` • `Zoom API` • `Spring Boot`
- **Features**:
  - 3 dedicated role-based portals (Admin, Teacher, Student) with RBAC & JWT
  - Real-time student-teacher messaging via Socket.IO
  - Automated Zoom API integration for scheduled live classes
  - 20+ modules: MCQ exam grading engine, attendance, fees, salary, and node-cron background automation
