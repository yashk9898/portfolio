## ✨ Portfolio Key Features

- **⚡ Zero Heavy Framework Dependencies**: Handcrafted using semantic HTML5, modern CSS3 variables & flex/grid, and modular vanilla JavaScript for near-instant 100/100 Lighthouse performance.
- **🔮 Cyberpunk & Glassmorphic Aesthetics**: Deep `#07080f` background with custom mesh gradient radial blobs, dynamic blur backdrops, and cyan/violet accents.
- **🖱️ Custom Physics Cursor**: Smooth dual-element cursor (center point + delayed elastic ring) with interactive scale triggers on clickable surfaces.
- **🧊 3D Hero & Card Tilt**: Mathematical mouse-tracking transforms with dynamic perspective on cards, mockups, and avatar badges.
- **📊 Interactive Application Mockups**:
  - **ATS.AI Admin Mockup**: Real-time simulated screening scorecard, match percentage badge (98% fit), skill tag parsing, and email workflow buttons.
  - **Lerning.com Control Room Mockup**: Sidebar navigation, attendance metrics, and animated bar chart.
- **✍️ Dynamic Role Typewriter**: Animated cycling developer roles and specializations.
- **📬 Asynchronous AJAX Contact Form**: Direct form submission integration with FormSubmit AJAX, input validation, and instant toast confirmations.
- **📱 Fully Responsive**: Fluid layouts adapted seamlessly across ultra-wide desktop monitors, tablets, and mobile screens.
